# PB-RAG-ASISTENTE-TARIFAS-ATM-BCN
Asistente de tarifas y abonos para la red ATM de Barcelona, que cubre Rodalías, Metro y Autobús para el curso de AI Engineering de The Bridge. El sistema deberá proporcionar información sobre abonos y tarifas, así como el abono recomendable a comprar según trayecto y recurrencia del trayecto. No es asistente de rutas, solo tarifas y abonos.
